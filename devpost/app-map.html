wovain app map

wovain is a ChatGPT plugin for print-on-demand sellers, served from a hosted MCP server. Inside one chat it turns an idea into a live Fourthwall product, makes video ads for it, and builds one Meta Advantage+ sales campaign guarded by five automated rules.

One action, end to end: “Add to campaign”

What happens between pressing Add to campaign on the ad card and seeing the campaign card with its rules.

  1. Ad card button records the choice, then posts a chat message.
    apps/cards/src/ad/ad-card.tsx · onAdd → tool record_ad
  2. Skill sees the message and starts the campaign steps.
    plugin/skills/wovain-campaign/SKILL.md
  3. Plan: budget in cents, ad names, product links with UTM tags.
    apps/server/src/tools/campaign.ts · campaign_plan
  4. Meta Ads connector builds the draft campaign, ad set and video ads.
    ChatGPT's Meta Ads connector (outside this repo)
  5. Rules: five payloads in cents, posted to Meta's rules API.
    apps/server/src/tools/campaign.ts · create_rules → packages/shared/src/rules.ts · metaRules → apps/server/src/lib/meta-graph.ts
  6. Campaign card shows Ready, Live or blocked, with each rule's threshold.
    apps/cards/src/campaign/campaign-card-view.tsx

Reference route: three stops

A reference route through the code above; it wasn't toured together.

1. The button · apps/cards/src/ad/ad-card.tsx, search onAdd

The card calls the server tool record_ad directly so the choice is saved even if the chat moves on, then sends “Added the ads for design d1 to the campaign” so the skill knows to continue.

2. The rules tool · apps/server/src/tools/campaign.ts, search "create_rules"

Reads the added ads and each product's breakeven from the store, builds the five rules, skips any that already exist in Meta, and records which ones are in place. Without a Meta token it creates nothing and returns the fix instead.

3. The thresholds · packages/shared/src/rules.ts, search metaRules

Turns breakeven × your Settings multiples into Meta filters in cents: for example 3 × breakeven spend with no sales pauses an ad. The test apps/server/test/campaign-tools.test.ts pins the PRD demo tee's numbers ($30.96 kill, $8.26 scale).

A practice to reuse

Keep money math out of the model, and pin it with a test. The skills pass copy and choices; prices, breakeven and rule thresholds are computed by the server from stored data (packages/shared/src/ad.ts says so at the top), and campaign-tools.test.ts checks the exact cents Meta receives. When the first live run sent the rules to Meta, the thresholds matched without a fix. On any agent-built app that moves money, compute the numbers in code the model calls, and write one test with a worked example from the spec.

Run it again

  • bun install, then copy .env.example to .env and fill in the keys you need.
  • bun run plugin:install installs the plugin in the ChatGPT desktop app, pointed at the hosted /mcp; restart the app.
  • For iteration: bun run plugin:dev plus bun run cards:watch.
  • See every card without ChatGPT: bun run storybook.
  • Checks: bun run check, bun run typecheck, bun test, bun run test:stories.
