## Principes

1. **Approuver, pas opérer.** Le vendeur décide ; wovain fait les clics.
2. **Montrer les preuves.** Les prix, marges et scores viennent avec des sources ou un calcul.
3. **Du réel, pas du factice.** De vrais produits, prix et stocks Fourthwall.
4. **Réutiliser, ne pas reconstruire.** Fourthwall, Meta, Qloo et les fournisseurs de modèles font le gros du travail.
5. **Le code impose les limites.** Les modèles décident dans des limites que le code applique ensuite.

## Marque

Nom : wovain (en minuscules). Voix : coach amical. Chaleureux, explique le pourquoi en une phrase et commence quand même par les chiffres, par exemple « La vidéo A ne vendait pas, je l'ai donc mise en pause pour économiser du budget : 30,96 $ dépensés, aucune vente. »

## Preuves

Il n'y a pas encore de clients, de ventes ni de témoignages, et aucun n'est revendiqué dans cette documentation.
