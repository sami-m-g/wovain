## Key decisions

- **One app, one API.** The website and the ChatGPT MCP server call the same oRPC procedures, so behavior cannot drift between surfaces.
- **Code enforces limits, models decide within them.** Nemotron replies are validated with Zod, and price, budget, trademark and spend limits are applied in code afterward.
- **Paused by default.** No procedure activates a Meta object.
- **Structured logs.** evlog emits one wide event per request, which the self-healing flow reads.
- **Typed environment.** Varlock schemas generate `ENV`, so a missing variable fails at start-up.
- **Cloud SQL on GCP** for PostgreSQL, reached through Drizzle.

## Seller flow in the API

Trends, designs, judge, approve, products, ads, campaign. Each stage persists its result, so a run can resume after a failure and an approval can happen on either surface.
