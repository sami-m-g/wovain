Wovain takes a solo print-on-demand seller from "what should I sell?" to live Fourthwall products and a paused Meta ad campaign, and the seller only approves.

Who is likely to buy comes from [Qloo](/docs/integrations/qloo). Why now comes from [Tavily](/docs/integrations/tavily). The judging and autopilot decisions come from [NVIDIA Nemotron on Nebius Token Factory](/docs/integrations/nebius-nemotron).

## The flow

1. Qloo and Tavily find trends: the audience's taste graph, then this week's news inside it.
2. Designs are generated for real Fourthwall blanks, placements and prices.
3. Nemotron judges each design against print rules and, in autopilot, makes the approval decisions within hard limits that code enforces.
4. You approve, on the website or in ChatGPT.
5. Wovain creates the Fourthwall products and several Meta ad variants.
6. Wovain builds a Meta campaign that stays **paused** until you start it.

## Where it runs

One Next.js 16 app (`apps/web`) serves the website, the oRPC API and the ChatGPT MCP server. See [Architecture](/docs/architecture).

After the code ships, three GitLab Duo flows keep it healthy: self-healing from production errors, a scout for KPI and UI improvements, and an issue-to-completion developer flow. See [Agent flows](/docs/agent-flows).
