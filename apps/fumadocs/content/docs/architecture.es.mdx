## Decisiones clave

- **Una aplicación, un único conjunto de procedimientos.** El sitio web los llama por `/api/rpc`; las herramientas MCP llaman al mismo router con `createRouterClient`, como el vendedor que inició sesión.
- **Los modelos deciden, el código pone las salvaguardas.** Las respuestas de Nemotron se validan con Zod; el tamaño de impresión, el precio mínimo, el rango de presupuesto y el estado en pausa son código.
- **En pausa por defecto.** Ningún procedimiento activa un objeto de Meta y los productos de Fourthwall se crean ocultos.
- **Tokens sellados.** Los accesos de Fourthwall y Meta se guardan cifrados con AES-256-GCM (`TOKEN_ENCRYPTION_KEY`).
- **Registros estructurados.** evlog emite un evento amplio por solicitud, que el flujo de autorreparación lee.
- **Entorno tipado.** Los esquemas de Varlock generan `ENV`, de modo que una variable ausente hace fallar el arranque.

## El flujo del vendedor en la API

`ideas.research` → `designs.generate` → `designs.approve` o `designs.reject` → `products.create` → `products.publish` → `campaigns.create`, o `runs.start` para todo. Cada paso guarda su resultado y una ejecución registra su paso actual y cualquier error.
