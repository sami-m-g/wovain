## Decisiones clave

- **Una aplicación, una API.** El sitio web y el servidor MCP de ChatGPT llaman a los mismos procedimientos oRPC, así que el comportamiento no puede divergir entre superficies.
- **El código impone los límites, los modelos deciden dentro de ellos.** Las respuestas de Nemotron se validan con Zod y después el código aplica los límites de precio, presupuesto, marcas y gasto.
- **En pausa por defecto.** Ningún procedimiento activa un objeto de Meta.
- **Registros estructurados.** evlog emite un evento amplio por solicitud, que el flujo de autorreparación lee.
- **Entorno tipado.** Los esquemas de Varlock generan `ENV`, de modo que una variable ausente hace fallar el arranque.
- **Cloud SQL en GCP** para PostgreSQL, accesible mediante Drizzle.

## El flujo del vendedor en la API

Tendencias, diseños, juez, aprobación, productos, anuncios, campaña. Cada etapa guarda su resultado, de modo que una ejecución puede reanudarse tras un fallo y una aprobación puede hacerse en cualquiera de las dos superficies.
