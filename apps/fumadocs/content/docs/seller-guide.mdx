You can run the same flow on the website or in ChatGPT. Both call the same oRPC procedures and the same database, so you can start in one and finish in the other.

## Connect your accounts

Sign in at [wovain.com](https://wovain.com), then connect the two services wovain acts on for you:

- **Fourthwall**, where your product is created and published.
- **Meta**, where the ad variants and the paused campaign are created.

Wovain never spends ad budget on its own. Every Meta object is created paused, and a Fourthwall product is created hidden until you publish it.

## On the website

1. **Seed.** Give a seed such as a niche, a fandom or a product theme.
2. **Trends.** Wovain shows ideas ranked by taste (Qloo) and moment (Tavily), with the evidence behind each score.
3. **Design.** Pick an idea. Nemotron writes the brief and listing, fal draws the print art and the price comes from the blank's base cost.
4. **Judge.** Nemotron checks the design and code checks the print size. You see the verdict, score and fixes.
5. **Approve.** Approve the design, or reject it with a reason.
6. **Product.** The approved design becomes a hidden Fourthwall product. Publish it when you are ready.
7. **Campaign.** Choose countries and a daily budget. Wovain writes up to three ad variants and builds a Meta campaign, ad set and ads, all **paused**. You start it in Meta.

## Connect wovain in ChatGPT

1. In ChatGPT, turn on developer mode and add a custom connector (an MCP server).
2. Enter the server URL: `https://mcp.wovain.com/api/mcp`. The OAuth settings are discovered automatically from `/.well-known/oauth-protected-resource` and `/.well-known/oauth-authorization-server`.
3. Sign in to wovain when ChatGPT opens the sign-in page, then approve access on the consent page.
4. Ask ChatGPT to run `list_connections`. For Fourthwall or Meta, open the connect link it returns and authorize.
5. Ask in chat: "research trends for retro hiking gear". ChatGPT calls `research_trends`, then `generate_design`, and asks you before it calls `approve_design`, `create_product`, `publish_product` and `create_campaign`.

Tools return JSON for now; widgets are not built yet.

## Autopilot

Ask for `start_run` with autopilot on, or start a run on the website with the autopilot option. Nemotron picks the idea and reviews the design, and the run goes on to the product, the publish step and a paused campaign. Code gates the run: a design the judge says to revise is never approved, the price keeps at least $10 profit and a 30% margin, the daily budget stays between $1 and $500, and nothing is activated. A failed run shows its step and error.

See [Nebius and Nemotron](/docs/integrations/nebius-nemotron) for how the decisions are made.
