wovain est aussi une application dans ChatGPT. Demandez un drop avec vos mots ; ChatGPT affiche les idées et les designs et vous demande avant de lister un produit ou de construire une campagne.

## Ajouter wovain à ChatGPT

1. Dans les paramètres de ChatGPT, activez le mode développeur.
2. Ajoutez un connecteur personnalisé avec cette URL : `https://mcp.wovain.com/api/mcp`.
3. Connectez-vous à wovain quand ChatGPT le demande, et autorisez l'accès.

## Lancer un drop

Demandez avec vos propres mots, par exemple :

> Fais un drop de printemps de dessins botaniques au trait, délavés, pour mon label.

ChatGPT suit les mêmes étapes que l'application web : idées, designs, votre validation, les produits et une campagne en pause. Si un compte n'est pas encore connecté, il vous donne un lien pour le connecter.

Les drops lancés dans ChatGPT apparaissent sous **Exécutions** sur le web, et inversement.
