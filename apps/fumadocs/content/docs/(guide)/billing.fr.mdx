## Qui facture quoi

Un drop implique quatre factures, chacune émise par le service qui fait le travail :

| Quoi | Facturé par | Quand |
| --- | --- | --- |
| wovain | wovain | Votre offre, voir les [tarifs](https://wovain.com/pricing) |
| Production et expédition | Fourthwall | Prélevé sur chaque vente ; rien à avancer |
| Visuels | fal | À l'image, sur votre compte fal |
| Publicités | Meta | Seulement après l'activation d'une campagne, à hauteur de votre budget quotidien |

Fourthwall reste le vendeur officiel de vos produits et vous verse votre profit.

## Les crédits vous sont rendus

La recherche consomme des crédits au départ. Si elle ne trouve aucune idée, wovain vous rend ces crédits, comme lorsqu'une étape échoue.

## Codes promo

Un code promo ajoute des crédits gratuits à votre compte. Ouvrez **Facturation**, saisissez le code sous **Utiliser un code** et sélectionnez **Valider**. Un code gratuit ne demande aucune carte, et ses crédits arrivent en quelques secondes. Ils n'expirent jamais.

Chaque compte peut utiliser un code une fois, et un code cesse de fonctionner après sa date de fin ou une fois toutes ses utilisations épuisées.
