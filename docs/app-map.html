wovain app map

An agentic print-on-demand app: Qloo finds who would buy, Tavily finds why now, Nemotron judges the designs, and the seller approves Fourthwall products and a paused Meta campaign.

Snapshot of source commit ce5d37c on the rebuild branch. Code drifts; the repository is the source of truth. Live: wovain.com, docs: docs.wovain.com.

The pieces

One Next.js 16 app (apps/web) serves the website, the API and the ChatGPT MCP server on Cloud Run. The API is a set of oRPC procedures (packages/api), sign-in is Better Auth (packages/auth) and data lives in PostgreSQL through Drizzle (packages/db). The docs are a separate Fumadocs site (apps/fumadocs) in English, French and Spanish.

One action, from click to result

The website calls /api/rpc; ChatGPT calls POST /api/mcp with an OAuth access token. Both reach the same appRouter.

Reference route: generate a design (3 stops)

A reference route, not a toured one. Search for the symbol if line numbers have moved.

Stop File Anchor What happens
1 packages/api/src/mcp.ts generate_design in createMcpServer The ChatGPT tool calls client.designs.generate as the signed-in seller. (The website calls the same procedure over /api/rpc.)
2 packages/api/src/flow/designs.ts generateDesign Writes the brief, draws the art, prices it, judges it and saves the design as pending_approval.
3 packages/core/src/design.ts judgeDesign, printFacts Nemotron judges the design; code decides the print size and overrides the model.

To change this, start here

Add or change a procedure or MCP tool

Edit packages/api/src/routers/index.ts (appRouter). Step logic lives in packages/api/src/flow/*; the matching ChatGPT tool is registered in packages/api/src/mcp.ts. Use protectedProcedure for anything that needs a signed-in seller.

Change a provider (Qloo, Tavily, Nemotron, fal, Fourthwall, Meta)

Each has a module in packages/core/src (qloo.ts, trends.ts, nemotron.ts, fal.ts, fourthwall.ts, ads.ts), wired together by createCore in packages/core/src/core.ts. Prices come from priceFor in pricing.ts.

Change sign-in or the ChatGPT connection

packages/auth/src/index.ts (createAuth, mcpResource); the routes are apps/web/src/app/api/auth/[...all]/route.ts, apps/web/src/app/api/mcp/route.ts (MCP URL https://wovain.com/api/mcp) and the OAuth discovery routes under apps/web/src/app/.well-known/. Never edit packages/db/src/schema/auth.ts by hand; run pnpm run auth:generate.

Change the database

Seller tables (run, idea, design, product, campaign, connection) are in packages/db/src/schema/seller.ts; generate a migration with pnpm run db:generate.

Change the docs or translations

Pages are in apps/fumadocs/content/docs with .fr.mdx and .es.mdx siblings; locales are set in apps/fumadocs/src/lib/i18n.ts. The planning documents are docs/scope.md, docs/prd.md and docs/spec.md.

A practice to reuse

Write the limit as an observable rule before building the feature. In this project, docs/prd.md says the print-size check is computed by code and overrides Nemotron, and the test "lets code decide print size over the model's word" in packages/core/src/design.test.ts proves it. That turns "the model should not underprice" into a test you can run, and the same habit works on any project that lets a model make decisions.

Run it again

pnpm install, docker compose up -d, then pnpm run dev. Before committing: pnpm run check, pnpm run check-types, pnpm run knip.
